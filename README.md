# Holographic Krylov Complexity

Code and data accompanying the MIORPA 2026 research report **"Holographic Krylov Complexity: Charged probes, fixed-charge Routhian reduction, and top-down quiver geometries"** by Géraud Ogounchi Badélé (Mathematical Institute, University of Oxford).

[![DOI](https://img.shields.io/badge/DOI-10.5281__zenodo.22675312-blue)](https://doi.org/10.5281/zenodo.22675312)

## Scientific description

Krylov (spread) complexity measures how a quantum state spreads along the Krylov basis generated by Hamiltonian evolution. A recent holographic proposal identifies the growth rate of spread complexity with the proper radial momentum of a bulk probe. This report addresses a specific consistency puzzle in that proposal: for probes carrying a conserved Noether charge (e.g. angular momentum on an internal cycle), a naive holographic momentum has a non-zero value at a radial turning point, contradicting the universal quantum result $\dot C_{\mathrm K}(0)=0$.

**Research question.** Can the holographic momentum–complexity dictionary be made consistent with the universal short-time behaviour of Krylov complexity when the bulk probe carries a conserved charge?

**Main result.** Yes, provided the comparison is made in the fixed-charge sector. A partial Legendre transform (Routhian reduction) with respect to the cyclic coordinate removes it from the reduced configuration space while retaining its energetic effect through a position-dependent effective mass $m_{\mathrm{eff}}(r) = \sqrt{m^2 + J^2/h(r)}$. The resulting reduced radial momentum vanishes at a turning point and grows linearly in time, exactly as required. This mechanism is derived analytically for a general charged point particle, obtained in closed form in global AdS$_3$, and verified numerically across three increasingly structured top-down backgrounds: global AdS$_3$, two six-dimensional $\mathcal N=(1,0)$ SCFT quiver geometries, and a quadratic-rank black-string-chain background.

## Installation

Requires Python ≥3.10 (developed and verified under 3.11.9 and 3.14.7).

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate       macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

To rebuild `report/Holographic_Krylov_Complexity_MIORPA_Report.pdf` you additionally need a LaTeX distribution (TeX Live or MiKTeX/TinyTeX) providing `pdflatex` and `bibtex`.

## Reproducing the main results

```bash
# 1. Global AdS3 benchmark: symbolic + numerical validation, regenerates ads3/holographic_krylov_validation.png
cd ads3 && python ads3_validation.py

# 2. Two 6d SCFT quiver geometries: main comparison, parameter scan, intercept plot, symbolic check
cd quiver_comparison
python run_quiver_comparison.py          # figures/01-08*.png, results_table.csv, parameter_scan.csv
python run_parameter_family_scan.py      # figures/09_f1_shape_vs_P.png, figures/10_scan_vs_P.png, parameter_family_scan.csv
python run_intercept_plot.py             # figures/09_naive_minus_routhian_intercept.png
python sympy_verify_quiver2.py           # independent symbolic re-derivation of alpha_2(eta) (stdout only)

# 3. Quadratic black-string-chain background (imports quiver_comparison/routhian.py by relative path,
#    so the two directories must remain siblings as in this repository)
cd blackstring_quiver
python run_blackstring_quiver.py         # figures/01-03*.png, tableA-D_*.csv

# 4. Rebuild the report PDF
cd report
pdflatex Holographic_Krylov_Complexity_MIORPA_Report.tex
bibtex Holographic_Krylov_Complexity_MIORPA_Report
pdflatex Holographic_Krylov_Complexity_MIORPA_Report.tex
pdflatex Holographic_Krylov_Complexity_MIORPA_Report.tex
```

All four steps were re-run from a clean copy of this repository on 2026-09-09 and reproduced the numbers quoted in the report (see `REPOSITORY_AUDIT.md` for the exact verification log).

## Main results (three computational components)

### 1. Global AdS$_3$ (`ads3/`)
`ads3_validation.py` independently re-derives, with SymPy, every boxed formula of the AdS$_3$ section (turning-point energy, first-order radial equation, initial acceleration, short-time slope $\alpha(J,m,r_0)$, and the neutral/boundary limits), then integrates the exact Euler–Lagrange equation with an adaptive 8th-order Runge–Kutta scheme (`DOP853`, rtol=atol$\sim10^{-13}$) and compares the numerically extracted short-time slope to the closed-form $\alpha(J,m,r_0)$. Worst relative error over the tested parameter set: $1.04\times10^{-7}$, matching the "at most $1.0\times10^{-7}$" claim in the report.

### 2. Two 6d SCFT quiver geometries (`quiver_comparison/`)
`geometry.py` builds the warp factors $f_1,f_2,f_3$ for Quiver 1 (triangular rank) and Quiver 2 (trapezoidal rank) from the rank functions of arXiv:2603.10106; `routhian.py` implements the generic fixed-charge Routhian reduction of Sec. "Top-down six-dimensional SCFT backgrounds". `run_quiver_comparison.py` reproduces the naive-vs-Routhian momentum comparison and parameter scan; `run_parameter_family_scan.py` scans the quiver size $P\in\{5,20,50,100,200\}$; `run_intercept_plot.py` isolates the intercept effect; `sympy_verify_quiver2.py` is an independent symbolic cross-check of Quiver 2's rank function. Reproduced naive-intercept values: $0.0877, 0.2630$ (Quiver 1, $J=1,3$), $0.2307, 0.6920$ (Quiver 2, $J=1,3$) — exact match to Table in Sec. "Two 6d SCFT quiver geometries" of the report.

### 3. Quadratic black-string-chain background (`blackstring_quiver/`)
`geometry.py` implements the D2–D4–D6–NS5 near-horizon background of Couzens et al. (arXiv:2109.10413) with a quadratic rank profile; `run_blackstring_quiver.py` reuses `quiver_comparison/routhian.py` unchanged (the two directories must remain siblings) and produces the well/barrier structure, the naive-vs-Routhian mechanism table, the $J$-independence-of-equilibrium check, and the UV-cutoff/displacement scan. Reproduced displacement scale: $\Delta z \sim 4.5\times10^{-7}$ at the reference benchmark, consistent with the "order $10^{-7}$" claim in the report.

# Scientific issues

This file is for scientific inconsistencies discovered while preparing the repository. No equations, numerical values, or physical conclusions in the report were altered during this process (see `CHANGELOG.md` for the only changes made, which are build-path/figure-path edits and the addition of a code-availability paragraph).

## Issue 1: figure with no recovered generating script

**Location:** Sec. 2 ("Universal short-time behaviour"), Fig. `fig:toy-ct`, `figures/ct_example.png`.

**Problem:** No script in the original project directory (checked all `.py` files and the notebook, including a search for `savefig`) produces this figure. It appears to have been generated by a scratch/console session that was not saved.

**Why it matters:** For a "publication-quality, reproducible" repository, every figure should ideally be regenerable from committed code. This one currently is not.

**Suggested correction:** Either (a) write a new, clearly-labeled script that reproduces the stated $3\times3$ toy Hamiltonian and its Krylov spread complexity curve (a few lines: build $H$, run Lanczos, evolve $|\psi(t)\rangle$, plot $C_K(t)$ vs $t^2$), or (b) keep the static PNG with the documented provenance gap. This audit did not take action (a) because it would be new code rather than recovered code, and the task instructions were explicit about not inventing code; the choice is left to the author.

**Verification status:** The *numerical claim* underlying the figure was independently hand-verified during this audit (direct Lanczos iteration on $H=\begin{psmallmatrix}2&1&0\\1&3&0\\0&0&4\end{psmallmatrix}$, $|\psi_0\rangle=(1,0,0)$, reproduces exactly $a_0=2,\,b_1=1,\,a_1=3,\,b_2=0$ as stated in the text). Only the figure-generating code, not the science, is missing.
